# JevRouter 功能演示路径与讲稿

> 面向对象：业务方 / 评审 / 客户
> 演示时长：**8 分钟**（可压缩至 5 分钟，可扩展至 10 分钟）
> 演示形态：云形态（前端 + 后端 API）
> 讲解基调：**只讲业务场景与业务价值，不展开代码逻辑与算法细节**

---

## 一、演示总览

### 1.1 一句话定位

JevRouter 是一套「**多模型智能路由中枢**」：业务只需把一个 prompt 丢进来，系统会自动判断这个请求「是什么意图、多复杂、要什么能力、多急、多在意成本」，再结合企业当前的模型清单与历史决策经验，**自动为它挑一个最合适的模型去执行**，并且整个过程可解释、可追溯、会自我进化。

### 1.2 要证明的三件业务价值

| 价值主张 | 用哪一幕证明 |
|---|---|
| **省心**：业务不用再纠结"用哪个模型"，一句话自动选型 | 幕二、幕三 |
| **省钱**：能用便宜/免费模型完成的任务，绝不调用贵模型 | 幕五、幕六 |
| **可信**：每一次选型都有依据、有记录、可复盘、可审计 | 幕三、幕六、幕七 |

### 1.3 时长分配（总计 8 分钟）

| 幕次 | 内容 | 时长 | 累计 |
|---|---|---|---|
| 幕 0 | 开场与价值锚点 | 0:30 | 0:30 |
| 幕 1 | Prompt 输入 | 1:00 | 1:30 |
| 幕 2 | 提交 → 3D 路由星图实时决策（**高潮**） | 2:00 | 3:30 |
| 幕 3 | 结果与决策解释 | 1:00 | 4:30 |
| 幕 4 | 智能路由流程图（选型逻辑一目了然） | 1:00 | 5:30 |
| 幕 5 | 模型能力（成本与质量的账本） | 1:00 | 6:30 |
| 幕 6 | 决策经验库（越用越聪明） | 1:00 | 7:30 |
| 幕 7 | 历史记录 + MCP 形态收尾 | 0:30 | 8:00 |

> **5 分钟压缩版**：保留幕 0 / 幕 1 / 幕 2 / 幕 6 / 幕 7，其余一句话带过。
> **10 分钟完整版**：在幕 5 追加"按厂商分组"视角，在幕 6 展开"动态阈值复算"，结尾追加 MCP Server 现场调用。

### 1.4 演示前准备清单

- [ ] 后端已启动：`cd packages/backend && pnpm dev`（默认 `http://127.0.0.1:3000`）
- [ ] 前端已启动：`cd packages/frontend && pnpm dev`，浏览器打开并**全屏**
- [ ] 打开"模型能力"页签确认模型清单已加载（避免现场等接口）
- [ ] 准备一条演示用 prompt（推荐用"快速示例"中的**代码审查**，复杂度适中、结果直观）
- [ ] 屏幕缩放 100%，关闭无关通知；投影分辨率 ≥ 1080p（3D 星图效果更佳）

### 1.5 应急预案

| 现场情况 | 应对 |
|---|---|
| 3D 星图卡顿 | 关闭浏览器其他标签页；或直接切到"智能路由"页签用 2D 流程图讲解 |
| 模型接口超时 | 使用"快速示例"重试一次；仍失败则切到**离线形态**演示（具备完整决策与偏差声明） |
| 低置信度走了免费兜底模型 | 这正是卖点，顺势讲解"拿不准就转免费模型"的兜底策略 |

## 二、演示路径与逐幕讲稿

### 幕 0 · 开场与价值锚点（0:30）

**操作**：展示系统初始界面（左侧 3D 星图 + 右侧面板），停留在"Prompt 输入"页签。

**讲解要点**：
> "企业现在同时接入了几十个大模型，每个模型能力、价格、速度都不一样。业务同事最头疼的问题只有一个：**这个任务到底该用哪个模型？**
> 用贵了浪费钱，用便宜了可能干不好，用错了还得重来。
> JevRouter 解决的就是这一个问题——**把'选模型'这件专业的事交给系统，业务只管提需求。**
> 接下来我完整跑一遍，8 分钟您就能看清它是怎么想的、怎么选的、怎么越来越准的。"

**埋钩子**：说明屏幕左侧的星图是"路由决策的实时过程可视化"，右侧是"业务操作区"。

---

### 幕 1 · Prompt 输入（1:00）

**操作**：
1. 指向右侧"Prompt 输入"区，说明支持富文本、实时字数与 token 估算（≤5000 字）。
2. 点击"快速示例"中的 **代码审查**，内容自动填入输入框。
3. 强调：**业务不需要任何配置、不需要选模型、不需要填参数**。

**讲解要点**：
> "业务侧的体验就一句话——**像用普通聊天工具一样，把需求写进去就行。**
> 您看这里有四个日常场景的快捷入口：代码审查、文案撰写、数据分析、翻译润色，覆盖了企业 80% 的高频需求。
> 注意输入框旁边的 token 估算——它会在提交前就预估这次请求的成本量级，这是后面'省钱'的第一个伏笔。"

**关键模块**：`InputTab.vue`（输入与场景预设）、`输入区字数/token 估算`

---

### 幕 2 · 提交 → 3D 路由星图实时决策（2:00，**全场高潮**）

**操作**：
1. 点击 **"开始 Jev 智能路由"**（或 ⌘/Ctrl+Enter）。
2. 视线引导到左侧 3D 星图，跟随光点/高亮的推进，逐段口播。
3. 快速示例：星图自左向右依次点亮 **Prompt 输入 → Jev 中枢 → 各家模型星球 → 决策库**。

**讲解要点（跟随星图节奏分段口播）**：

- **（0:00-0:30）理解请求**
  > "首先系统不会急着选模型，而是先'读懂'需求：这是一个什么意图的请求、复杂度多高、需要什么能力、紧急程度、以及对成本敏不敏感。"

- **（0:30-1:00）匹配候选**
  > "接着它把企业当前**在线的、可用的**模型全部拉出来，逐个比对——注意，模型星球是实时从模型清单生成的，新上线的模型会自动进入候选。"

- **（1:00-1:30）层层筛选**
  > "然后是一道道'硬门槛'：数据敏感度能不能过、上下文够不够长、预算够不够、延迟能不能接受。**不满足的模型在这一步就被淘汰，根本不会浪费调用成本。**"

- **（1:30-2:00）给出结论**
  > "最后系统给出一个'把握程度'：有把握就直接路由，把握一般就路由但标记观察，**如果把握不足，就自动切换到免费兜底模型**——宁可结果普通一点，也不让业务为不确定性买单。
  > 整套决策过程，2 秒内完成，而且是**全程可见的**，不是黑盒。"

**关键模块**：`StageView.vue` + `TreeScene.ts`（3D 二叉路由树可视化）、后端决策主链（理解请求 → 候选匹配 → 约束筛选 → 打分选型 → 置信度路由）

**引导金句**：
> "这朵星图不只是一个动画——**它就是系统的'思考过程'**。每一个灯亮起，都是一次真实的业务判断。"

---

### 幕 3 · 结果与决策解释（1:00）

**操作**：
1. 向下滚动到"执行结果"区，展示模型返回的流式输出。
2. 打开"决策解释"（Response/Result 区），展示 **置信度 / 档位 / 选中模型 / 事件数** 四个关键指标。
3. 逐条念出 Jev 的判断依据。

**讲解要点**：
> "结果出来了，但更重要的是**右边的这四行字**：
> **置信度 0.87、档位 ROUTE、选中模型 ×××、事件数 14**。
> 这意味着：系统对这个判断有 87% 的把握，因此直接路由、自动执行。
> 下面这五条是它的判断依据——意图、复杂度、能力要求、紧急度、成本敏感度。**业务看完这段，就知道系统为什么选它，而不是拍脑袋。**
> 如果哪天结果不符合预期，也不需要重跑猜谜，**这条决策凭据就是复盘的依据。**"

**关键模块**：`ResultTab.vue`（决策解释五项）、决策凭据（决策可审计）

**价值锚点**：从"黑盒抽卡"变成"白盒可解释"。

---

### 幕 4 · 智能路由流程图（1:00）

**操作**：切换到 **"智能路由"** 页签（3D 星图停在上方或切回 2D 流程）。

**讲解要点**：
> "刚才那 2 秒钟发生的事，在这里被完整摊开成一张图。您可以把它理解成**路由中枢的'工作台'：**
> 左边是**模型能力**——回答'现在有哪些模型、各自什么水平'；
> 中间是**主链路**——一条从'接入'到'落库'的十步流水线，每一步在做什么，写得很清楚；
> 右边是**决策经验库**——回答'门槛该设多高、过去的经验是什么'。
> 三者在这里交汇，共同产出最终的选择。**业务同学不需要懂技术，也能看懂系统是讲道理的。**"

**关键模块**：`RoutingTab.vue`（三列流程图）、候选模型池（可现场勾选参与路由的模型）

**可选互动**：现场取消勾选某个贵模型，重新提交，演示"候选池约束"如何影响结果。

---

### 幕 5 · 模型能力（1:00）

**操作**：切换到 **"模型能力"** 页签。

**讲解要点**：
> "这是企业模型资产的**统一账本**。每个模型按四个维度展示：
> **总体评价**——综合评级与业界评分；
> **能力**——上下文长度、支持的模态、能力标签；
> **价格**——每千 token 的输入/输出价格，**免费模型会明确标出来**；
> **胜出记录**——它被选中多少次、胜率多高、平均延迟多少。
> 有了这本账，'该不该上一个更便宜的模型''这个贵模型到底值不值'，就不再靠感觉，而是靠数据。"

**关键模块**：`ModelsTab.vue`（四维模型画像）、模型清单 API（实时/回落/种子三级来源）

**可选扩展（10 分钟版）**：切换"按厂商分组"视图，说明多厂商统一接入与横向比价。

---

### 幕 6 · 决策经验库（1:00，**价值升华**）

**操作**：切换到 **"决策经验库"** 页签。

**讲解要点**：
> "这是整套系统**最有价值的部分——它会越用越聪明。**
> 上半部分：**当前的路由门槛**（比如'置信度 ≥ 0.82 直接路由'）。这个门槛不是写死的，而是随着系统积累的决策样本**自动复算、动态调整**。
> 中间部分：**每个模型的历史战绩**——谁被选得多、谁胜率高、平均把握度多少。
> 下半部分：**最近每一次决策的完整明细**——五问判断、候选分布、淘汰原因、执行统计，全部留存。
>
> 这意味着两件事：
> 第一，**新任务进来时，系统会参考历史经验做先验修正**，一模一样的请求不会再走弯路；
> 第二，**企业沉淀下来的是一份不断增值的'选型经验资产'**，而不是一次次用完即弃的调用。"
> 每次决策都会**自动落库、自动复算门槛、自动更新模型战绩**——形成闭环。**这就是'越用越准、越用越省'的机制来源。**

**关键模块**：决策经验库（阈值供给 + 经验沉淀）、经验闭环（沉淀 → 统计 → 应用 → 复现 → 验证）

---

### 幕 7 · 历史记录 + MCP 形态收尾（0:30）

**操作**：
1. 切换到 **"历史记录"** 页签，用搜索框演示按关键词检索。
2. 收尾话术点出 MCP 形态：**同一套路由能力，可以不用页面，直接以接口形式嵌进业务系统 / AI 助手。**

**讲解要点**：
> "所有跑过的请求都在这里，按小时归档，支持关键词搜索、点开看完整明细——**这就是审计与复盘的入口。**
> 最后补充一点：这套路由能力**不依赖这个页面**。它同样以标准接口（MCP）暴露，可以**直接嵌进你们现有的业务系统或 AI 助手里**——也就是说，能力可以复用，展示只是它的一种形态。
>
> 回到最开始那三个问题：**该用哪个模型、会不会浪费钱、选错了怎么办**——JevRouter 的答案是：**自动选、算着花、有据查。**"

## 三、关键模块及其作用（讲解参照，不逐条念）

> 演示时**不必**逐一点名模块，只需在对应幕次自然关联其业务作用；下表供讲者备查。

| 模块 | 位置 | 业务作用（讲什么） |
|---|---|---|
| **Prompt 输入区** | 前端 `InputTab` | 业务唯一操作入口，零配置提交需求 |
| **3D 路由星图** | 前端 `StageView` / `TreeScene` | 把"系统思考过程"可视化，建立信任 |
| **结果与决策解释** | 前端 `ResultTab` | 让每次选型有依据、可复盘 |
| **路由流程图** | 前端 `RoutingTab` | 一张图讲清"模型库 + 主链路 + 经验库"三者关系 |
| **候选模型池** | 前端 `RoutingTab` | 让业务按需圈定参与路由的模型范围 |
| **模型能力账本** | 前端 `ModelsTab` | 成本 / 质量 / 战绩的统一视图，支撑比价决策 |
| **决策经验库** | 前端 `DecisionTab` | 展示"动态门槛 + 模型战绩 + 决策明细"，体现自进化 |
| **历史记录** | 前端 `HistoryTab` | 审计、检索、复盘入口 |
| **路由中枢（后端）** | 后端决策主链 | 理解请求 → 筛选候选 → 打分选型 → 置信度路由 |
| **硬约束门** | 后端约束筛选 | 数据合规、上下文、预算、延迟的前置拦截，避免无效成本 |
| **经验闭环** | 后端经验存储 | 决策自动沉淀、阈值自动复算，实现"越用越准" |
| **模型网关** | 后端多模型接入 | 多厂商模型统一接入与调用，屏蔽差异 |
| **MCP 服务** | 独立协议层 | 让路由能力脱离页面，嵌进任何业务系统 / AI 助手 |
| **离线形态** | 前端离线适配 | 无后端也能演示与运行，并明确声明偏差 |

## 四、讲者速查卡（一页版）

**开场**：企业接了几十个模型 → 业务只想知道"这活该用谁" → JevRouter 自动选型。

**主线**：写需求 → 提交 → 看星图（理解为先、筛选淘汰、结论三档）→ 看解释（置信度/档位/依据）→ 看流程（三库关系）→ 看账本（成本质量）→ 看经验（越用越准）→ 看历史（可审计）。

**三句金句**：

1. "这朵星图不是动画，它就是系统的思考过程。"
2. "拿不准就转免费兜底模型——不让业务为不确定性买单。"
3. "别人沉淀的是调用日志，我们沉淀的是不断增值的选型经验资产。"

**收尾**：**自动选、算着花、有据查。**
